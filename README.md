# حقوق درمان

اپ حقوقی فارسی (Flutter، اندروید) + سرور نرخ دیه (Flask).

| پوشه | محتوا |
| --- | --- |
| `server/` | سرویس `GET /api/v1/diyeh-rates` — راهنمای نصب: `server/README.md` |
| `server/data/` | فایل نرخ و ضرایب دیه (یک فایل برای هر سال) |
| `server/docs/` | توضیح کامل فیلدهای فایل نرخ |
| `app/` | اپ Flutter (در حال ساخت) |

قاعده‌ی نام‌گذاری فایل‌ها: `NAMING.md`

همه‌ی ویرایش‌های زیر روی سرور و در فایل‌های پوشه‌ی `/opt/diyeh-api` انجام می‌شود. **بعد از ذخیره، ری‌استارت لازم نیست** و اپ‌ها بدون آپدیت عدد جدید را می‌گیرند (حداکثر تا یک ساعت، به‌خاطر کش). قبل و بعد از هر ویرایش، فایل را بررسی کنید:

```bash
cd /opt/diyeh-api && sudo venv/bin/python validate_rates_v1.py data/diyeh_rates_1405.json
```

## تغییر نرخ دیه

### وسط سال (تغییر نرخ همان سال)
در `data/diyeh_rates_1405.json` فقط این‌ها را عوض کنید:
- `full_diyeh_toman`: عدد صحیح، بدون ممیز و بدون جداکننده؛ مثلاً `2500000000`
- `updated_at`: تاریخ ویرایش؛ مثلاً `"1405-11-01"`

### سال جدید
۱. یک کپی با نام سال جدید بسازید:
```bash
cd /opt/diyeh-api/data && sudo cp diyeh_rates_1405.json diyeh_rates_1406.json
```
۲. در فایل جدید `year`، `full_diyeh_toman` و `updated_at` را عوض کنید.
۳. فایل جدید را بررسی کنید (`validate_rates_v1.py data/diyeh_rates_1406.json`).
۴. در `server_config.json` فقط این خط را عوض کنید:
```json
"current_rates_file": "data/diyeh_rates_1406.json",
```
فایل سال قبل پاک نمی‌شود و برای برگشت کافی است همین خط را برگردانید.

## تأیید آیتم pending
آیتم‌های `"status": "pending"` در اپ دیده نمی‌شوند. برای نمایش یک آیتم:
- `status` را از `"pending"` به `"approved"` تغییر دهید؛
- `article` (شماره‌ی ماده) و در صورت امکان `source_url` (لینک https) را پر کنید.

برای پنهان کردن دوباره، `status` را به `"pending"` برگردانید.

## نکته‌های مهم ویرایش
- کسرها همیشه داخل گیومه و به شکل `"1/20"` نوشته شوند؛ عدد اعشاری (`0.05`) پذیرفته نمی‌شود.
- اگر فایل خطا داشته باشد، سرور همان نسخه‌ی سالم قبلی را می‌دهد؛ ولی تا خطا رفع نشود، تغییر شما هم اعمال نمی‌شود. لاگ: `sudo journalctl -u diyeh-api -n 50`
