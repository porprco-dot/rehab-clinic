# ساختار فایل نرخ دیه (schema_version: 1)

فایل: `server/data/diyeh_rates_1405.json` — همین فایل از `GET /api/v1/diyeh-rates` برگردانده می‌شود و یک کپی از آن داخل اپ برای حالت آفلاین قرار می‌گیرد.

همه‌ی کسرها **رشته** هستند (مثل `"1/20"`) و با محاسبه‌ی کسری دقیق حساب می‌شوند؛ فقط عدد نهایی به تومان گرد می‌شود (نیم به بالا).

## فیلدهای سطح بالا

| فیلد | معنی |
| --- | --- |
| `schema_version` | نسخه‌ی ساختار فایل. اپ اگر نسخه‌ی ناشناخته ببیند، از کش/پیش‌فرض استفاده می‌کند. |
| `year` | سال نرخ دیه |
| `full_diyeh_toman` | دیه‌ی کامل به تومان (عدد صحیح) |
| `haram_extra_fraction` | سهم اضافه‌ی ماه حرام (فقط روی آیتم‌هایی که `haram_applicable: true` دارند) |
| `updated_at` | تاریخ شمسی آخرین ویرایش |
| `female_rule` | قاعده‌ی دیه‌ی زن (پایین) |
| `payment_schedule` | زمان‌بندی پرداخت بر اساس نوع جنایت |
| `texts` | همه‌ی متن‌های ثابت صفحه |
| `groups` | گروه‌های فهرست آسیب‌ها و ترتیب نمایش |
| `items` | آسیب‌ها |

## `female_rule`

| فیلد | معنی |
| --- | --- |
| `threshold_fraction` | آستانه (یک‌سوم دیه‌ی کامل) |
| `organ_factor` | ضریب کاهش دیه‌ی اعضا بعد از رسیدن به آستانه |
| `nafs_factor` | ضریب دیه‌ی نفس زن |
| `threshold_scope` | **هنوز تعیین نشده (`null`)** — مقادیر ممکن: `"total"` (روی مجموع آسیب‌ها) یا `"per_item"` (روی هر ردیف) |
| `reduction_mode` | **هنوز تعیین نشده (`null`)** — مقادیر ممکن: `"whole"` (کل مبلغ نصف شود) یا `"excess_only"` (فقط مازاد بر یک‌سوم) |

تا وقتی این دو فیلد `null` باشند، اپ گزینه‌ی جنسیت را نشان نمی‌دهد و محاسبه را برای مرد انجام می‌دهد.

## `items` — هر آیتم

| فیلد | معنی |
| --- | --- |
| `id` | شناسه‌ی یکتا |
| `group` | یکی از `id`های `groups` |
| `category` | `"nafs"` یا `"organ"` (برای قاعده‌ی دیه‌ی زن) |
| `title` | عنوان نمایشی |
| `short_title` | اختیاری. عنوان کوتاه وقتی این آیتم به‌عنوان «نوع دندان» در آیتم‌های دیگر انتخاب می‌شود؛ اگر نباشد، `title` نمایش داده می‌شود. |
| `calc_type` | نوع محاسبه (پایین) |
| `quantity` | `null` یعنی تعداد پرسیده نمی‌شود؛ وگرنه `{label, min, max}` |
| `haram_applicable` | سؤال ماه حرام برای این آیتم نمایش داده شود یا نه |
| `article` | شماره‌ی ماده |
| `source_url` | لینک منبع؛ `null` یعنی دکمه‌ی «منبع» پنهان است |
| `status` | `"approved"` نمایش داده می‌شود؛ `"pending"` پنهان است |
| `note` | یادداشت زیر نتیجه؛ `null` یعنی بدون یادداشت |

### انواع `calc_type`

| مقدار | فیلدهای لازم | فرمول |
| --- | --- | --- |
| `fixed` | `fraction` | `fraction × تعداد × دیه‌ی کامل` |
| `relative_to_base` | `multiplier`، `base_options`، `base_label` | کاربر نوع دندان را از `base_options` انتخاب می‌کند: `کسر آیتم پایه × multiplier × تعداد × دیه‌ی کامل` |
| `percent_of_base` | `base_options`، `base_label`، `percent_input` | `کسر آیتم پایه × (درصد ÷ ۱۰۰) × دیه‌ی کامل` |

آیتم‌های داخل `base_options` باید از نوع `fixed` باشند.

## `payment_schedule.options`

هر گزینه: `id`، `title`، `description`، و `installments` (فهرست کسرها، هر عضو سهم یک سال قمری؛ جمع کسرها باید ۱ باشد).

## کارهای رایج

- **تغییر نرخ سالانه:** فقط `full_diyeh_toman`، `year` و `updated_at` را عوض کنید.
- **تأیید آیتم pending:** `status` را از `"pending"` به `"approved"` تغییر دهید (و `article` و `source_url` را پر کنید).
